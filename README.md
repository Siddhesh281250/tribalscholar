# TRIBAL SCHOLAR — Clickable Prototype

This prototype is derived from the supplied build brief.

## Included
- Applicant and Ministry Officer role switch
- Scheme discovery
- AI preliminary eligibility checker
- Multi-step application concept
- Document upload + simulated AI verification
- Deficiency → resubmission loop
- Officer Application Intelligence Center

## Run
Open `index.html` directly in a browser. No installation or server is required.

## Important
This is a demonstration prototype, not a production government system. Data is fictional. AI, OCR, PFMS/DBT and identity integrations are simulated.
